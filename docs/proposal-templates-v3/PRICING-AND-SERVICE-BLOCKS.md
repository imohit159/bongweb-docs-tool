# Pricing Plans and Service Blocks

Two internal documents that make proposals fast and consistent. Clients never see them directly; their content is copied into proposals.

**Status:** not created yet. Needs the list of services Bongweb sells at launch.

## Pricing Plan (rate card)

A price list for each service, with what each plan includes. Answers: _how much do we charge, and what does each price include?_

Example for "Business Website". The numbers below are illustrative, not decided prices.

|                                | Basic          | Standard              | Premium            |
| ------------------------------ | -------------- | --------------------- | ------------------ |
| Best for                       | New businesses | Most local businesses | Growing businesses |
| Pages                          | 3              | 5                     | 8                  |
| Contact form + WhatsApp button | ✓              | ✓                     | ✓                  |
| Online booking                 | —              | ✓                     | ✓                  |
| Revision rounds                | 1              | 2                     | 3                  |
| Free support after launch      | 15 days        | 30 days               | 60 days            |
| Timeline                       | 2 weeks        | 4 weeks               | 6 weeks            |
| **Price**                      | **₹15,000**    | **₹30,000**           | **₹50,000**        |

Copied into **section 5 (Investment)** of the Project Proposal, or **section 3 (Plans)** of the Retainer Proposal. In proposals, the columns run Premium → Standard → Basic, highest first.

## Service Block

A ready-written description of one service. Answers: _what exactly are we delivering, and what are we not?_

Example for "Business Website":

|                      |                                                                                                    |
| -------------------- | -------------------------------------------------------------------------------------------------- |
| **What you get**     | Mobile-friendly website, contact form, Google Maps, WhatsApp button, basic SEO setup, handover walkthrough |
| **Revision rounds**  | As per the chosen plan                                                                             |
| **We need from you** | Logo, photos, page text, domain login, by the kick-off date                                        |
| **Not included**     | Content writing, product photography, paid plugins, domain and hosting fees                        |

Copied into **section 3 (Our solution)** of the Project Proposal. One block per service; a client wanting a website and branding gets both blocks.

## How they fit into a proposal

```
Project Proposal for Lotus Salon
├── 2. Problems        ← written fresh for each client
├── 3. Our solution    ← copy the service blocks (Website + Branding)
├── 5. Investment      ← copy the pricing plan rows
└── everything else    ← already in the template
```

## Why

- **Speed:** only Problems and Summary are written fresh; a proposal takes about 20 minutes instead of 2 hours.
- **Consistency:** two clients asking for the same website get the same price and scope.
- **Fewer disputes:** "Not included" lines are written carefully once, not forgotten under deadline pressure.
